## 2024-03-21 - Active Session Input Locking
**Learning:** Permanently locking rows after submission (like workout sets) can cause frustrating typo lock-ins. When users are in an active session, they expect to be able to undo or edit their submitted data quickly.
**Action:** Always provide an 'undo' or edit toggle for submitted data states within an active session, rather than permanently disabling the interactable elements.
