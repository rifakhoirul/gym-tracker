## 2024-05-24 - Prevent Typo Lock-in for Submitted States
**Learning:** Hard-locking UI elements (like form inputs or workout set rows) immediately upon submission can create extreme frustration when users make simple typos. The immediate feedback is "you can't fix your mistake", which ruins trust in the application.
**Action:** Always provide an 'undo' button or toggle functionality for submitted data states within an active session, allowing the user to un-submit, correct their typo, and re-submit rather than permanently disabling the inputs.
