## 2024-03-01 - Prevent Typo Lock-in on Workout Sets
**Learning:** Users often make typos when logging workout sets on a mobile device. If a "Done" button permanently disables the input state, a simple typo becomes an unfixable mistake in their workout history. We need to prioritize correct data entry by keeping states editable.
**Action:** Always provide an 'undo' or edit toggle for submitted data states within an active session (e.g., workout sets), rather than permanently locking the row.
