## 2024-05-24 - Undo for Submitted Data States
**Learning:** Users can experience frustration and "lock-in" when they make typos on form inputs that get permanently submitted without an option to reverse. Providing an undo or edit toggle for submitted data states within an active session (like a workout set) is a critical UX pattern.
**Action:** Changed the "Done" state of the set completion button to be toggleable. When pressed, it turns into "Undo" rather than a permanently disabled checkmark, and restores the ability to edit the weight and reps fields.
