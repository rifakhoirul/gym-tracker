## 2024-10-18 - Workout Set Lock-in

**Learning:** Permanently disabling a completion button immediately after a user submits data (like logging a workout set) causes severe frustration if they made a typo. Users expect to be able to immediately undo or edit an action they just performed within an active session.

**Action:** Always provide an 'undo' or edit toggle for submitted data states within an active session, rather than permanently locking the row, to prevent frustrating typo lock-ins.
